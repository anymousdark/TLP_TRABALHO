Relatório Completo — Painel Administrativo

Conteúdo gerado para documentar a correção aplicada no projeto (loja_virtual), evitando o fatal fetch_assoc() on bool em admin.php.
Status: Corrigido —

1) Resumo do Problema

Fatal Error
Arquivo afetado
admin.php
Mensagem
fetch_assoc() em bool

O erro acontece quando $conn->query(...) falha e retorna false. Em seguida, o código tenta chamar fetch_assoc() diretamente sobre esse retorno. Isso quebra a página no carregamento.

Exemplo do padrão inseguro (antes): $total_prod = $conn->query("SELECT COUNT(*) as c FROM produtos")->fetch_assoc()['c'];
Dica: esse tipo de fatal geralmente ocorre por tabela inexistente, SQL inválido ou indisponibilidade do banco.

2) Alteração Aplicada

Proteção
  • Foram corrigidas as queries de estatísticas em admin.php.
  • Agora cada query() é checada antes do fetch_assoc().
  • Fallback automático para 0 quando a query falha.
Exemplo do padrão seguro (depois): $q_total = $conn->query("SELECT COUNT(*) as c FROM produtos"); if ($q_total !== false) { $row = $q_total->fetch_assoc(); $total_prod = intval($row['c'] ?? 0); }
Objetivo: manter o painel funcionando mesmo quando o banco estiver temporariamente inconsistente.
